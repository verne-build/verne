# Customize a project icon

Verne selects a project icon automatically. It checks `verne.json` or `t3.json`, common favicon
and app icon paths, and icon links in project HTML files. When both project files exist,
`verne.json` is authoritative.

To choose a different icon:

1. Open **Settings** and select **Projects**.
2. Select the project.
3. Under **Appearance**, select **Choose a project file**.
4. Search for an image file and select it.

Verne supports SVG, PNG, ICO, JPEG, GIF, AVIF, and WebP files. The selected path applies to
each checkout in the project group and appears on your connected clients.

To use automatic detection again, select **Automatic**.
